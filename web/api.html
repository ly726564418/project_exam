接入约定

POST /ingest 接收原始 JSON 消息。202 表示整条消息已可靠保存；业务校验与物化异步完成。429 表示背压，413 表示超出 2 MiB，507 表示存储预算不足。原文、失败原因及处理状态可通过 receipt_id 追溯。

curl -fsS http://localhost:8000/healthz
curl -fsS 'http://localhost:8000/api/objects?run=your-run&limit=50'
curl -fsS http://localhost:8000/api/stats

属性路径形如 mass_solar 或 orbit.altitude_km。列表采用 cursor 游标分页；数值范围只比较 JSON 数字。各批次用 run 隔离，未指定时选择最近的批次。
